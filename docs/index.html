      How this map was made

      • Every .lean file was parsed as text to list declarations with their statements and source lines. Private ones are kept per file, as Lean does.
      • The browser loads the roughly 8,000 declarations nearest the main theorems plus the most reused ones. The full index of about a million declarations is rebuilt locally by the indexer in the repository.
      • This shows structure, not meaning. It is not a proof check: that was done by Lean's kernel and independent checkers.

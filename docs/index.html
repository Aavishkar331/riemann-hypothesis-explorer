Explore the machine proof of the Riemann Hypothesis

On 20 November 2026, Levent Alpöge and Claude released a proof of the Riemann Hypothesis written in Lean, a language a computer can check line by line. It runs to 17 million lines, far too much to read. This page turns it into a map you can walk through.

  1. 1Pick one of the five main theorems below.
  2. 2The map shows what it is built from (right) and what builds on it (left).
  3. 3Click any box to step into it. Each step takes you one level deeper into the proof.

How this map was made

  • Every Lean file was read as text to list each declaration with its statement and source line.
  • To stay fast, the browser loads about 8,000 declarations: the ones nearest the main theorems plus the most reused. Counts like "uses" and "used by" are for the whole proof.
  • This shows how the proof is put together. It does not check it; Lean's kernel and independent checkers did that.

Proof by Levent Alpöge with Claude. Source: the Lean community's riemann-hypothesis repository.
